The user wants Overview to answer what to do today: weekly focus, today's planned sessions, reserved versus logged time, and one next action. Missed work needs clear recovery choices, not red judgmental warnings.

**Why:** The user asked for a simple, calm daily planning experience while preserving every existing page, feature, and the existing data model.

**How to apply:** Keep stored entities and backward compatibility. Introduce optional metadata rather than replacing existing areas or measure definitions. Category is separate from life area; never guess old goals' categories from their area. Unclassified goals are Other; work without a goal is General work.

Pace forecasts must use measured progress, never task checkoffs or reserved time. Treat even pace as a reference and completion dates as estimates; explain when there is insufficient history. Keep partial first measurement periods intact.

**Why:** The user requested current progress, expected pace, forecast completion, and an actionable recommendation instead of "behind linear pace."

**How to apply:** Keep forecast wording conditional and preserve weekly/monthly period boundaries. Weekly review has five steps: wins, misses, carryover tasks, next week's focus, and one commitment for Monday. Show intended changes before final save and keep all AI record changes behind explicit confirmation.
